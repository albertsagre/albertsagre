### Hi, I'm Albert Sagré Martínez 👋

**Systems and controls engineer working on vehicle software validation and moving into autonomy: control, motion planning and robotics.** Based in Barcelona.

I've spent the last few years making real vehicles behave as specified: validating powertrain software, calibrating engines and e-drives, and testing ADAS functions on test benches, lab cars and test tracks. I'm now building on that with the software that makes vehicles autonomous: state estimation, control and motion planning.

#### What I work on
- **Now:** Software Validation Engineer at Capgemini Engineering, working on McLaren powertrain software. I run system-level tests on vehicles, test benches and lab cars, turn requirements into test procedures, and do diagnostics and trace analysis.
- **Before:** powertrain calibration at Nissan, e-drive calibration and validation at Punch Powertrain, and ADAS validation at CUPRA.
- **Studying:** MSc in Systems and Control Engineering (UNED). My courses cover nonlinear and multivariable control, autonomous robots and computer vision.
- **Interested in:** control and motion planning for autonomous vehicles, eVTOL and drones; state estimation and sensor fusion; model-based development and simulation.

**[Vision-Based Autonomous RC Car](https://github.com/albertsagre/jetracer-autonomous-driving)**: an RC car that drives itself using only a camera, running on an NVIDIA Jetson Nano. It uses a ResNet-18 network optimised with TensorRT, adjusts its speed according to the steering, avoids obstacles, and shows everything on a live operator dashboard. Bachelor's thesis, UPC 2023. The speed-control logic has been refactored and tested against the original code that ran on the car.
